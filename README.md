### 🧠 Overview

The **AVL Tree Visualizer** is an interactive web-based tool that demonstrates how **AVL Trees** maintain balance through **rotations** after each insertion or deletion.  
It provides a **clear step-by-step visualization** for learners to understand how balancing works in real-time.

---

### 🚀 Live Demo  
👉 [**Click Here to Try It Out**](https://avl-tree-balancer.onrender.com/)  

---

### 🧩 Features

- 🌱 Visualize **AVL Tree insertions and deletions** dynamically  
- 🔄 Demonstrates **LL, RR, LR, and RL rotations** clearly  
- 📈 Auto-balances nodes after every operation  
- 🧮 Shows **height and balance factor** for each node  
- 🧠 Great for learning **Data Structures & Algorithms**
